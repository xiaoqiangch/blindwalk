# 步迷 Walkaholic · 产品需求文档（MVP）

> 一句话：**不看见终点，才看得见路。**
> 打开一个「散步盲盒」，它只带你走，不告诉你去哪；到了，才揭晓这个地方藏着的小惊喜。
> 面向一个人散步的孤独时刻，用一次小小的未知，把日常重新变得有趣。

状态：v0.1 MVP 设计冻结（2026-11-08）· 负责人：Lead · 实现：designer / ios-dev / watch-dev

---

## 1. 背景与洞察

- **问题**：大城市里大量单身 / 独居年轻人「想出门但没理由」，散步变成刷手机的另一种形式；周末计划成本高、决策疲劳。
- **洞察**：盲盒的快乐来自「未知 + 轻量 + 可收藏」。散步恰好具备前两点，缺的是仪式感、目的地和一点点赌运气。
- **对标参考**：抖音「散步盲盒」（不会写代码的作家用 AI 做的散步盲盒，验证了需求存在）。
- **差异化**：不做「附近推荐」，做「**目的地保密的仪式化散步 + 收集 + 弱社交**」。核心不是地图，是**揭晓那一刻**。

## 2. 目标用户

| 画像 | 场景 | 诉求 |
|---|---|---|
| 独居上班族（25–35） | 下班后 / 周末下午想走走 | 不用做决定，有一点期待 |
| 异地 / 单身青年 | 一个人吃饭、一个人散步 | 被陪伴感、可分享的小确幸 |
| 城市探索爱好者 | 新城市 / 老城区 | 发现算法推不到的地方 |

非目标：不服务多人聚会规划、不做严肃运动记录、不做真实导航替代品。

## 3. 核心体验循环（Core Loop）

1. **抽**：选时长（15/30/60 分钟）+ 心情（放空 / 发现 / 热闹）→ 摇出盲盒。
2. **走**：只显示方向、距离和随距离解锁的线索，不显示终点；地图上没有目的地图标。
3. **揭**：进入 30 米范围自动「开盒」——地点名、稀有度、为什么是这里、一个 1 分钟小任务。
4. **收**：收录回忆卡，得惊喜值（XP），可能触发成就。
5. **晒 / 约**：发布到圈子、生成同频码和朋友一起走、冲周榜。

一次完整体验 15–60 分钟；单次收益：1 张卡 + 20~60 XP + 可能 1 个成就。

## 4. MVP 功能清单（P0）

| 编号 | 功能 | 说明 | 验收标准 |
|---|---|---|---|
| F1 | 盲盒生成 | 本地规则引擎，按心情/时长/区域从内置地点库抽 1 个，避开 7 天内去过的 | 同参数多次抽取有变化；不重复最近地点 |
| F2 | 三阶线索 | 按剩余距离 400m / 200m / 60m 依次解锁，措辞不暴露地名 | 3 条线索，前两条可读、第三条是「快到了」氛围句 |
| F3 | 保密导航 | 只显示方向箭头 + 剩余距离 + 抽象路线，不显示终点名称/图钉 | 全流程无地名提前泄露 |
| F4 | 到达揭露 | ≤30m 自动触发开盒动画 + 地点卡（名称/类别/稀有度/编号/为什么是这里） | 到达后 1.5s 内出现卡片 |
| F5 | 小任务 | 每个地点一张 1 分钟任务卡，完成后打卡 | 打卡后 XP 增加、卡片标记完成 |
| F6 | 回忆册 | 卡片图鉴（3 列网格），含锁定态、稀有度、区域筛选、收集进度 | 新卡即时入册；刷新后仍在（持久化） |
| F7 | 成就系统 | 10 个成就，含进度条与解锁动画 | 达成条件即解锁并弹 toast |
| F8 | 圈子（弱社交） | 动态流（mock 好友 + 本人发布）、同频码、周榜 | 发布动态后出现在流顶部；同频码可复制/展示 |
| F9 | 手表伴行 | 进度环 + 距离 + 线索 + 震动揭晓 + 打卡 | watch 端 4 个界面可用（演示数据） |
| F10 | 演示模式 | 无 GPS 环境可模拟步行（原型必备） | 「模拟步行 +50m」按钮可推进至揭晓 |

P1（原型只留入口，不实现）：真实 GPS/定位、后台推送、Apple 登录、多城市扩展、付费隐藏款。

## 5. 非目标（本期不做）

- 真实地图瓦片、真实 POI 数据接入（原型使用虚构/示意地点库）
- 服务端、账号体系、真实好友关系链（用本地 mock + 同频码演示）
- App Store 上架材料、隐私合规细节（README 中标注待办）

## 6. 关键指标（用于后续验证）

- 完走率：抽盒 → 到达 ≥ 55%
- 7 日留存代理：连续开盒 ≥ 2 次用户占比
- 分享率：揭晓后发布 / 分享 ≥ 20%
- 同频参与率 ≥ 15%

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 地点安全 / 隐私（尤其夜间） | MVP 地点库限定公共场所；夜间只推明亮、人多类别；首次使用安全提示 |
| 不显示目的地导致迷路 | 始终给方向 + 距离；「我迷路了」降级为直接显示附近地标 |
| 抽到「没意思」的地方 | 稀有度 + 小任务兜底；「换一个」冷却 1 次/天 |
| 独自行走安全 | 一键分享行程给好友（P1）；原型中展示安全提示文案 |
