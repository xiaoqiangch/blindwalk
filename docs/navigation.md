# 旅程导航：不画地图，只给转向与提前量

> 状态：v1 已实现并验证（2026-11-09）
> 动机：用户反馈「地图没有任何意义」，需要的是「30 米后左拐」这种带提前量的导航。

---

## 1. 为什么去掉地图

| 问题 | 说明 |
|---|---|
| 信息噪音 | 手绘抽象地图和真实街道对不上，用户看不出自己在哪条路 |
| 破坏神秘感 | 地图上任何一个小点、路名都可能提前暴露目的地 |
| 占空间 | 地图吃掉了 40% 屏高，线索和距离被挤到下面 |

现在旅程页从上到下只有：**导航面板 → 剩余距离 + 方向 → 线索 → 接下来的转向 → 按钮**。

---

## 2. 数据从哪来

用 **Valhalla 公共步行路由**（`https://valhalla1.openstreetmap.de/route`），
公开、无需 Key、CORS 全开（`access-control-allow-origin: *`）。

一次请求拿到：
- 步行路线长度（`leg.summary.length`）
- 转向序列：`maneuvers[]`，每个含 `type`（转向类型）、`length`（这一段多长）、`begin_shape_index`（在路线上的位置）
- 路线形状：`leg.shape`（polyline6 编码，本地解码成经纬度点序列）

> 注意：Valhalla 即使传 `shape_format: geojson` 也可能返回 polyline6 字符串，所以要自己解码。

---

## 2.1 用户反馈的三个问题与修法（v2）

用户实测反馈：「导航信息混乱、更新周期不对、两个数字互相矛盾、箭头指得不准」。

| 问题 | 根因 | 修法 |
|---|---|---|
| **两个数字矛盾** | 大数字是「到目的地的直线距离」，接下来列表是「沿路线的转向距离」，两套口径 | 全页只保留**一个距离数字**：有路线时=沿路线剩余；线索里的「再走 X 米」也用同一数值换算 |
| **箭头不准** | 屏幕上同时有两个箭头：一个指目的地（绝对方位角，没罗盘时等于瞎指），一个指下一步转向 | 只保留**一个箭头**，含义固定＝下一步动作（↑直行 / ↰左拐 / ↱右拐 / ◉到达）；无路线时**不画箭头**，避免指错 |
| **更新周期不对** | 每次定位都整页重渲染，且「接下来」「线索距离」是渲染时写死的，走路后不更新 | 改为**局部刷新**：定位只更新导航卡文本，600ms 节流；「接下来」「线索距离」跟着刷新；只有线索解锁/到达这种结构变化才整页重渲染 |
| 转向提示来回跳 | 阈值附近 GPS 抖动导致「28 米后左拐」↔「现在左拐」反复 | **滞回**：喊过「现在左拐」后，必须走过该转向点 8 米才换下一句 |

## 3. 指令怎么算

### 3.1 沿线进度（关键）
不用直线距离估算进度，而是把当前位置**投影到路线折线**上：
```
routeProgress(route, here) → { walked: 沿路线已走米数, offRoute: 偏离路线米数, total }
```
这样转向点才会按真实里程触发。

### 3.2 转向文案（提前量分层）

| 距下一个转向 | 箭头 | 主文案 | 副文案 |
|---|---|---|---|
| > 45 米 | ↑ | 继续直行 | `X 米后左拐` |
| 13–45 米 | ↰/↱ | `X 米后左拐` | 注意路口 |
| ≤ 12 米 | ↰/↱ | 现在左拐 | 拐过去继续走 |
| 直行段 | ↑ | 继续直行 X 米 | 保持在同一条路上 |
| 距目的地 ≤ 25 米 | ◉ | 就在前面 | 抬头看看周围 |

卡片在「现在左拐」时变琥珀高亮（边框 + 实心箭头）。

### 3.2.1 全页只有一个数字

导航卡底部：`还剩 878 米 · 约 12 分钟`
线索锁文案：`再走 334 米，解锁第二条线索`（= 剩余 - 阈值）
「接下来」：各转向点的距离（从同一次沿线进度计算）

三处都来自同一个 `walked`，所以不会打架。

### 3.3 接下来两步
「接下来」卡片列出后面最多 3 个转向及距离，让人知道路线形状，不用盯着手机。

### 3.4 走错路
`offRoute > 80 米` 时重算路线（限频 45 秒一次），避免一直指错方向。

### 3.5 没有路由服务时
退回原来的方向提示：`往西走 / 还有 299 米`，并用会话里的方位角算箭头。**不会白屏、不会卡住。**

## 4. 保密规则仍然成立

- 导航只反映「怎么走」，不暴露目的地名称/地址/照片
- 转向列表只显示方向与距离，不含街道名（Valhalla 返回的英文路名没有直接展示）
- 目的地在最后 25 米才用「就在前面」提示，到了才揭晓

## 5. 验证记录

| 场景 | 结果 |
|---|---|
| 人民广场 → 上海博物馆（690m 步行路线） | ✅ 58 个路线点、10 个转向点 |
| 旅程页 | ✅ 无地图；面板「继续直行 51 米 / 保持在同一条路上」 |
| 走到一半 | ✅ 面板「28 米后左拐 / 注意路口」（提前量生效） |
| 临近目的地 | ✅ 「就在前面」→ 到达自动揭晓 |
| 屏蔽 Valhalla | ✅ 退回「往西走 / 还有 299 米」，无崩溃 |
| 折叠屏（466×678） | ✅ 面板收紧，仍在首屏 |
