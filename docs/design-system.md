# 盲走 BlindWalk · 设计系统与界面契约 v1（实现唯一依据）

> 所有实现（web 原型 / iOS / watchOS）必须遵守本文件。改动先改本文件，再通知 Lead。
> 语气：**温柔、轻微诗意、有一点点坏笑**。不卖萌、不励志鸡汤、不用「亲」。

---

## 1. 品牌

- 中文名：**盲走**；英文：**BlindWalk**
- Slogan：**不看见终点，才看得见路。**
- 副标语（揭晓页）：**这个地点，只为你亮一次。**
- 图标概念：一个系着细绳的牛皮纸盒子，盒面一个「?」，盒缝透出一点暖光。
- 关键词：牛皮纸、暖光、手写标签、城市、夜晚、路上。

## 2. 视觉基调

「**黄昏的旧地图**」：奶油纸底 + 墨色字 + 琥珀色光 + 一点点像被太阳晒旧的纹理。
不要：渐变紫蓝、科技蓝、玻璃拟态、复杂 3D 插画。插画用**扁平几何 + 线条**，可用少量 emoji 点缀。

稀有度徽章文字：常见 / 稀有 / 史诗 / 隐藏。

### 字体
- 系统栈：`-apple-system, "SF Pro Display", "PingFang SC", "Noto Sans SC", sans-serif`（web 直接系统字体，不加载外部字体）
- 字号：Display 40/44（距离数字、等级）；Title 22/28；Body 15/22；Caption 12/16；微标 10/12 大写+字距 0.08em
- 数字用等宽数字（`font-variant-numeric: tabular-nums`）

### 圆角 / 间距 / 阴影
- 卡片 24px；大面板 28px；按钮 999px；小标签 999px；图片 16px
- 间距基数 4：4 / 8 / 12 / 16 / 20 / 24 / 32；页面左右留白 20px
- 阴影：`0 12px 32px rgba(23,20,16,.10)`；悬浮层 `0 18px 48px rgba(23,20,16,.16)`
- 纸纹：低透明度噪点（web 用内联 SVG feTurbulence，opacity .035）

### 动效
- 主缓动 `cubic-bezier(.22,1,.36,1)`；快 180ms，常规 320ms，慢 520ms
- 摇盒 600ms（左右 ±6° 三次）；开盒 900ms（盒盖弹开 + 光溢出）；卡片翻面 520ms
- 呼吸光点 2.4s 循环；数字滚动 400ms
- 触感（native）：轻触 = light，解锁线索 = medium，揭晓 = success/pattern

## 4. 信息架构

底部 Tab 4 个（全屏旅程页隐藏 Tab）：

1. **今日**（盒子图标）— 首页 / 抽盒入口 / 上次惊喜 / 好友在走
2. **图鉴**（卡片堆图标）— 回忆册
3. **圈子**（双人图标）— 动态流 / 同频码 / 周榜
4. **我的**（人像图标）— 等级 / 成就 / 统计 / 设置

流程页：`抽盒设置 sheet → 旅程（全屏）→ 揭晓（全屏覆盖）→ 收录成功`。

## 7. Web 原型技术契约（designer 实现）

**必须完全离线、零依赖、双击 index.html 可跑**（file:// 可用；不允许 import / fetch 本地 json）。

- 文件：`prototype/web/index.html`、`styles.css`、`app.js`、`data.js`、`watch.html`、`README.md`
- 单页 hash 路由：`#/home`（默认）、`#/setup`、`#/journey`、`#/reveal`、`#/cards`、`#/social`、`#/profile`、`#/achievements`、`#/watch`；刷新后保持当前路由
- 演示数据：`data.js` 定义 24 个地点（字段：id, name, area, category, categoryEmoji, rarity, why, task, hint1, hint2, hint3, coords{x,y}（0–1 归一化地图坐标）, date, collected）
- 状态存 `localStorage['blindwalk:v1']`；URL `?demo=1` 预置「18 张已收集 / 12 天连续 / 240 惊喜值 / 正在走第 3 个盲盒」；`?fresh=1` 清空；`#/reveal?demo=1` 直接展示已预置的揭晓卡
- 模拟步行：`#/journey` 显示剩余 480m，按「+50m」递减；起点已有第 1 条线索，剩余 ≤200 / ≤60 时解锁第 2/3 条；≤30 触发开盒；进度存内存即可（刷新可重置，但 tab 间保持）
- 演示数据 `?demo=1`：xp 4240（Lv.6 黄昏猎人，240/800）、连续 12 天、18 张卡（稀有 7 / 隐藏 1）、总里程 42.6km、18 盒、2 条本人动态、6 条动态流、周榜本人第 4（305 分）、正在走 3 号盲盒（旧码头边的石阶，1260m 已走 780m）
- 设计稿尺寸：390×844 逻辑像素；`@media (min-width: 480px)` 时居中显示设备外框（桌面预览用），否则全屏
- 无障碍：按钮 `aria-label`；对比度达标；`prefers-reduced-motion` 时关闭粒子/摇盒
- 性能：无外部请求，首屏 < 1s
- 禁止：真实地图瓦片、外部 CDN 字体/图标库、图片外链

## 8. Native（iOS 17 / watchOS 10）契约

- 共享核心 `Shared/Core`（Lead 提供，Foundation-only，可被 macOS 编译校验）
- iOS 视图放 `App/`，watch 视图放 `WatchApp/`，共享视觉 tokens `Shared/Design/Theme.swift`
- iOS 用 `@Observable` + `@State`，不用第三方框架
