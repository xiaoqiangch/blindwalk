# 三端功能对齐规格（以 Web v32 为基准）

> 目标：iOS / HarmonyOS 与 Web 功能一致、体验相近。所有常量以本文为准，改动需三端同步。

## 1. 真实地点来源（三端一致）

优先级：**后台策展 `pois.json` → 多数据源（高德/百度/OSM/维基）→ 明确失败**。
**禁止**：任何虚构/程序生成的兜底地点（真实模式下）。

| 数据源 | 接口 | 说明 |
|---|---|---|
| 高德 | `GET https://restapi.amap.com/v3/place/around` | `location=lon,lat`（GCJ-02，需 WGS→GCJ 转换）、`radius`、`offset≤25`、`page`、`extensions=all`、可选 `keywords`；**每页 25 条、最多翻 3 页** |
| 百度 | `GET https://api.map.baidu.com/place/v2/search` | `query=生活服务`、`location=lat,lon`（BD-09）、`scope=2`、`page_size≤20` |
| OSM | Overpass API | 3 个镜像，单端点 4.5s、整体 8s |
| 维基 | `zh.wikipedia.org/w/api.php?action=query&list=geosearch` | 带缩略图 |

**Key 下发**：不写死、不让用户填。按顺序读：
1. 同目录 `mapkeys.json`（部署产物，结构 `{keys:{amap,baidu},version}`）
2. 后台公开端点 `GET {adminBase}/api/public/mapkeys`
3. 都没有 → 只用 OSM+维基

## 2. 选点策略：三档放宽（三端一致）

| 档 | relax | 搜索半径倍数 | 最小距离 | 最大距离 |
|---|---|---|---|---|
| 1 严格 | 0 | 1× | `max(168, 0.35×时长米)` | `1.7×时长米` |
| 2 放宽 | 1 | 1.8× | `max(120, 0.25×)` | `2.2×` |
| 3 很宽 | 2 | 3.2× | `max(86, 0.18×)` | `2.7×` |

- **硬帽**：`maxDistance = min(3500, 3.4×时长米)`，任何档位都不得突破
- 时长米：15 分钟=240m，30 分钟=480m，60 分钟=960m
- 每档都带一次**地标关键字**查询：`公园|风景名胜|博物馆|展览馆|广场|图书馆|书店|体育馆|寺|教堂|古镇`
- **质量门槛**：本档结果若"够真实但不够格"（见软黑名单），先记下，继续下一档；三档都没有更好的才用它

### 类别权重（distinctive）
`park 1.7 · museum 1.7 · temple 1.6 · historic 1.6 · garden 1.5 · viewpoint 1.5 · art 1.5 · library 1.5 · venue 1.4 · bookstore 1.4 · bridge 1.2 · river 1.2 · market 1.2 · plaza 1`
非良好类别 ×0.35；relax≥1 ×0.6；relax≥2 ×0.85。维基/OSM 来源 ×1.25，有照片 ×1.15。
**择优**：按权重降序取前 40%（至少 3 个）做加权随机。

### 失败时（无任何真实地点）
明确面板，文案：「没找到真实地点，这次不抽了」+「不会用虚构地点糊弄你」+ 每个源失败原因 + 三个按钮：`扩大范围再找` / `换个位置` / `改成演示模式（虚构地点）`。
绝不自动进入虚构地点。

## 3. 迷雾路径视图（三端一致）

- 朝向：**行进方向朝上**（heading-up）
- 前方可见 `min(260, 剩余-25)` 米；后方可见 `min(140, 已走-5)` 米
- 两端各 **46 米**渐隐（按 3 米插值逐段降透明度）
- 已走部分：灰褐 `#C9A98A`，线宽 7，不透明度 0.55；前方：琥珀 `#E89B4C`，线宽 9
- 每 **55 米**一个行进箭头（沿线方向）
- 「你」：白底琥珀圈 + 深色三角箭头；偏离路径 >18m 画红色虚线 `#D25C3A` 并提示「你离路径约 N 米」
- 右下角指北针（指针按 -bearing 旋转）
- **剩余 < 60 米**：整段隐藏，只显示「就在附近 · 抬头看看周围」
- 绝对不画终点、不画街道名

## 4. 账号（三端一致）

接口见 `account/docs/API.md`：`register / login / logout / me / PUT me/profile / DELETE me`。
- Cookie 会话（HttpOnly），客户端需带凭据
- 未登录：本地单机可用
- 登录后：`同步到账号`（整包覆盖）、`从账号恢复`（覆盖本机）、`退出`、`删除账号`
- 服务地址可配置，默认 `http://127.0.0.1:8803`

## 5. 字号（对齐 Web v32）

正文 14–16，次要 12–13.5，标签 10–12.5，大数字 22–30；不再使用 <10pt 的字号。
