# 埋惊喜 · 寻惊喜（Surprise Exchange）

> 一句话：**你在某个地方埋下一张照片，等一个陌生人来找到它，拍出同款。双方都得到点数。**
> 这是「盲走」从「一个人和城市」升级到「人和人」的关键一步。

状态：v0.3 首个社交深度功能 · 设计 v1（2026-11-09）· Lead 设计、surprise-dev / pwa-dev 实现

---

## 1. 为什么是这个功能

盲走原来的社交是「晒卡 + 周榜」，是**广播式**的：我发出去，别人点赞。弱。
而「埋惊喜」是**点对点**的：我埋下 → 某个人真的走到那里 → 拍出同款 → 我们都爽。它满足三件事：

1. **给予的快感**：不是被要求做事，而是主动留了个东西给未知的人。
2. **被找到的惊喜**：作者收到「有人找到了你的照片」时，比被点赞强烈得多。
3. **真正的探索**：寻者必须**先拍后看**——不给他看原图，逼他用自己的眼睛找角度。这是整个功能的核心。

## 2. 核心循环

```
埋（作者）                         寻（寻者）
─────────────                    ─────────────
① 拍一张自己觉得好的照片
② 写一句话：为什么埋在这里
③（可选）写一句提示
④ 在当前位置「埋下」
       ↓（离开，照片留在那里等人）
                                  ⑤ 在附近看到「一个惊喜在等你」
                                  ⑥ 走近，三阶线索逐级解锁
                                  ⑦ 进入范围 → 只能「这样拍一张」（看不到原图！）
                                  ⑧ 拍完 → 揭晓作者原图 + 并排对比 + 相似度
                                  ⑨ 达标 → 结算：寻者 +80 / 作者 +40
       ←───────────────────────── ⑩ 作者收到「有人找到了」
```

## 3. 奖励设计

| 动作 | 寻者 | 作者 | 理由 |
|---|---|---|---|
| 埋下一个惊喜 | +30（埋下即得） | +30 | 鼓励给予，不等结果先给回报 |
| 找到并复刻成功 | **+80** | **+40** | 探索是重活，给更多；作者被动获得，给一半 |
| 拍到但没达标 | +10 | 0 | 不打击人，但也不稀释奖励 |
| 被找到 5 次 | — | 成就「被找到的人 💌」 | 长期被需要的价值感 |

**防刷**：同一惊喜只能被找到一次（`status = found` 后不再出现）；同一个人不能找自己埋的。

## 4. 匹配算法：dHash 感知哈希

不用 AI、不用云端，两端各算一次，离线可用。

1. 照片 → 缩放到 **9×8** 灰度
2. 每行相邻像素比较：左边 < 右边 记 1，否则 0 → **64 位差异哈希**
3. 两张图比较：**汉明距离**（不同位数）
4. 相似度 = `max(0, 1 - 距离/32)`
5. **达标阈值 0.45**

为什么用 dHash 而不是像素差：拍照角度/光线会变，但**结构关系**（明暗走向）稳定。
实测：同一张图 self = 1.0；整体加亮 12 级 ≈ 1.0（不受影响）；反色 = 0.0；完全不同 = 0.0。

评价文案（温柔、不打击）：

| 相似度 | 文案 |
|---|---|
| ≥0.85 | 几乎一模一样。你找到了 TA 的视角。 |
| 0.65–0.85 | 很像。你站的位置差不多就是那个点。 |
| 0.45–0.65 | 有点像。再往那边挪两步会更接近。 |
| <0.45 | 画面不太一样。不过这张也有你自己的意思。 |

## 5. 关键设计决策

### ADR-007 先拍后看（不预先展示作者原图）
- 若先给原图，用户会直接照着摆拍 → 变成找角度复刻，失去「用自己的眼睛发现」的意义。
- 决策：**进入拍摄流程前，任何界面都不出现作者照片**；拍完后才揭晓。
- 代价：用户可能拍偏。用三阶线索 + 温柔点评 + 可重拍来兜。

### ADR-008 远距离开放探索（不做实时社交）
- 不要求作者和寻者同时在线；惊喜一直留在那儿（默认 30 天）。
- 好处：异步、不催、不打扰，符合「一个人的散步」的调性。

### ADR-009 本地优先存储
- MVP 把惊喜存在设备本地（照片在沙盒、元数据在 localStorage/UserDefaults）。
- 预置 3 条「别人埋的」演示数据让单人也能立刻体验闭环。
- v0.4 接后端（Supabase）实现真实跨设备交换。

### ADR-010 照片只存在本地，不上传（MVP）
- 隐私最小化：不传服务器，就不会泄露拍摄位置与画面。
- 代价：换设备不同步。v0.4 上传时需明确授权与模糊化处理。

## 6. 安全与隐私

- 照片可能拍到人脸/门牌：提供「打码/裁切」建议文案；v0.4 上云前做自动人脸模糊。
- 只允许埋在自己**当前所在**的位置（不能远程埋到别人家门口）。
- 展示给寻者时，作者只显示昵称与 emoji，不显示账号信息。
- 默认条数上限（每人每天 3 个），防刷屏。

## 7. 界面与文案契约

### 7.1 埋惊喜 `#/bury`
- 标题「埋下一张照片」· 副标「它留在这里，等一个人来找到。」
- 照片区（未选时：虚线框 + 「拍一张 / 从相册选」）
- 输入：`写一句话：为什么埋在这里`（≤60 字，占位「比如：这张是我在等一杯咖啡时拍的。」）
- 输入：`（可选）给找它的人一句提示`（≤40 字，占位「不能直接说答案哦。」）
- 位置行：`📍 静安 · 街角`（无定位时 `📍 演示位置 · 静安`）
- 主按钮「埋在这里」· 埋下后 toast「已埋下 · 神秘值 +30」

### 7.2 寻惊喜 `#/seek`
- 标题「附近的惊喜」· 副标「N 个照片在某个角落等你。」
- 卡片：作者 emoji + 昵称 · 距离「480 m」· 区域「静安 · 街角」· 文案「一张照片，在某处等你。」+ 右箭头
- 空状态：「这附近还没有人埋下惊喜。要不要先埋一个？」

### 7.3 寻惊喜详情 `#/seek/:id`
- 顶部：作者卡（emoji + `小满 埋在 · 静安` + `3 天前`）
- 线索时间线 3 条（同 journey 样式，按距离解锁）
- **范围外**：主按钮禁用「再走近 260 m」
- **范围内**：主按钮「这样拍一张」+ 小字「先别急着看，找到你的角度。」
- **拍完后**：
  - 两张照片并排（左：`TA 的` / 右：`你的`）
  - 相似度徽章 `78% 像`
  - 评价文案
  - 达标：`找到 · 探索值 +80` 大数字 + `作者 +40` 小字
  - 不达标：`再往那边挪两步` + 次按钮「重拍一张」

### 7.4 我的 `#/surprises`
- 分两段：「我埋的」（等待中 N / 被找到 M，含谁找到 + 对比图）· 「我找到的」（含对比图与相似度）

### 7.5 首页入口卡
- 位置：首页「上一次的惊喜」下方
- 文案：「惊喜社区」微标 + 一句「留一张照片给陌生人，或者去找到别人的。」
- 两个按钮：「埋下一个 ▲」「去寻宝 · 3 个在等你」
- 右侧小字：`我埋了 2 · 找到 1`

## 9. 验收（Definition of Done）

- [ ] 埋：选图/拍照 → 写话 → 定位 → 提交 → localStorage/沙盒有记录 + toast + 成就
- [ ] 寻：列表显示预置 3 条；详情三阶线索按距离解锁
- [ ] **核心**：范围外不显示原图；范围内只出「这样拍一张」；拍完才并排对比
- [ ] 匹配：dHash 真实算分，阈值 0.45；达标/不达标两条分支文案与点数正确
- [ ] 成就：bury_1 / seek_3 / found_5 可触发
- [ ] 无定位/无相机时降级可用且界面明确标注「演示」
- [ ] 公网 PWA 可正常走到上述全流程；可离线
