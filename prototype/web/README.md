# 盲走 BlindWalk · Web 高保真交互原型 v0.1

> 不看见终点，才看得见路。
> 打开一个散步盲盒，它只带你走，不告诉你去哪；到了，才揭晓这个地方藏着的小惊喜。

零依赖、纯原生 HTML/CSS/JS、**完全离线**的高保真原型。视觉与文案依据 `docs/design-system.md`，地点/成就/动态数据逐字镜像自 `apple/Shared/Core/*.swift`。

---

## 1. 怎么打开

**双击 `index.html` 即可**（Chrome / Safari / Edge，`file://` 直接可用）。

也可以用任意静态服务器（可选，非必需）：

```bash
cd Projects/BlindWalk/prototype/web
python3 -m http.server 8080
# 打开 http://localhost:8080/index.html
```

不需要安装、不需要构建、不会发出任何网络请求（字体用系统字体，图形全部内联 SVG/CSS/emoji）。

### 演示地址

| 参数 | 效果 |
|---|---|
| `index.html?demo=1#/home` | **推荐**。演示态：xp 4240（Lv.6 黄昏猎人，240/800）、连续 12 天、18/24 张卡（稀有 7 / 隐藏 1）、42.6 km、18 盒、本周惊喜值 **305**、周榜本人**第 4**、正在走 3 号盲盒（旧码头边的石阶，剩余 480m） |
| `index.html?fresh=1#/home` | 清空 localStorage，回到新用户态（0 卡、0 天、空动态流） |
| 无参数 | 读取 `localStorage['blindwalk:v1']`；没有存档则给新用户态 |
| `#/reveal`（可配 `?demo=1`） | 直达揭晓卡（旧码头边的石阶 / 稀有 / No.0247），跳过开盒动画 |

> `#setup` 路由会打开抽盒 sheet；`#/reveal?demo=1` 这类 hash 内 query 也支持。

## 3. 演示路径（完整闭环，约 60 秒）

1. 打开 `index.html?demo=1#/home` → 点主卡 **「开一个盲盒」**
2. 设置 sheet：选「30 分钟 · 刚好」+「发现」+「河边」→ **「摇一个盲盒」**（盒子左右摇 600ms）
3. 进入旅程：剩余 **480 米**，地图上是保密光点，第 1 条线索已解锁，第 2 条提示「再走 280 米」
4. 连点 **「模拟步行 +50m」**：480 → 430 → … → 180（≤200 解锁第 2 条）→ 80 → 30（≤60 解锁第 3 条，≤30 自动开盒）
   （也可以点 **「我到了」** 直接触发）
5. 全屏「到了」闪屏 → 开盒动画 1.2s → 揭晓卡（稀有 / No.xxxx）
6. 点 **「收进图鉴」**：+40~60 惊喜值（稀有款 +50）、写入 localStorage、弹出「已收录」toast，触发的成就会在 0.6s 后追加 toast；卡片有飞入图鉴的收束动画
7. 点 **「分享」**：发布动态到圈子（本人动态置顶），toast「已分享到圈子」
8. 去 **图鉴 / 圈子 / 成就 / 我的** 核对数据一致；刷新页面数据仍在

演示态（`?demo=1`）里额外可看到：收集第 3 盒（旧码头边的石阶）时因为该地点已在 18 张卡中，图鉴数量不变，但 XP / 盒数 / 里程照常增加；分享后「分享欲」成就从 2/3 变 3/3，会弹成就 toast。

### 演示数据口径

- 首页/周榜惊喜值：`最近 7 天到达 × 20 + 非普通卡 × 15 + 已完成小任务 × 5` = **305**
- 等级：`xp / 800 + 1`；4240 xp → Lv.6，240/800
- 线索门槛（镜像 `QuestSession.hintThresholds`）：起点解锁第 1 条，剩余 **≤200m** 第 2 条，**≤60m** 第 3 条，**≤30m** 到达

## 4. 文件

```
prototype/web/
├── index.html     # 应用外壳：状态栏 / tab bar / 弹层挂载点（9 条 hash 路由）
├── styles.css     # Design Tokens + 全部组件样式 + 纸纹噪点 + 地图/表盘/动效
├── app.js         # 状态机、hash 路由、渲染、抽盒引擎、旅程推进、收录/分享、localStorage
├── data.js        # 24 个地点 + 10 个成就 + 动态/周榜/心情/时长/区域 + 演示态（逐字镜像 Swift Core）
├── watch.html     # 3 块 198×242 表盘并排（720×360 截图用）
└── README.md
```

核心逻辑：

- **状态**：`localStorage['blindwalk:v1']`（档案 / 旅程 / 动态 / 设置）；hash 路由与旅程进度在切 tab、刷新后保持
- **抽盒**：区域过滤 + 稀有度权重（常见 70 / 稀有 22 / 史诗 6 / 隐藏 2，隐藏款只在 60 分钟开放）+ 7 天内去过的不重复 + 心情加权
- **无障碍**：按钮/图标均带 `aria-label`，进度条 `role="progressbar"`，`prefers-reduced-motion` 降级全部动效（含摇盒、开盒、地图呼吸、彩纸）

## 5. 截图 / 自测

### 手机 390 × 844

直接用普通浏览器缩放或截图工具模拟 390×844 即可：视口 < 480px 时是**全屏应用**（无外框）；≥ 620px 时是**桌面居中设备预览**（带外框 + 底部说明）。

> Chrome 在 macOS 上 headless 有 **500px 最小窗口宽度**，`--window-size=390,844` 的截图会被裁切。为此 480–619px 这一窄桌面区间采用**无边框全屏**模式，保证该命令截出的 390×844 仍然完整；精确 390×844 建议用 CDP `Emulation.setDeviceMetricsOverride({width:390,height:844,deviceScaleFactor:2,mobile:true})`。
>
> 截图前请留出动画时间：摇盒 600ms、开盒 1.2s、卡片翻面 520ms、sheet 上滑 340ms（静态路由本身无覆盖层）。

### 本次自测结果（Chrome DevTools Protocol，390×844）

- 50 项断言全部通过，**0 个 JS 异常 / 0 条 console error / 0 条 Log error**
- 9 条路由全部可直达；所有页面 `scrollWidth ≤ viewport`（无横向滚动）
- 闭环实测：首页 CTA → setup（时长/心情/区域）→ 摇盒 600ms → 旅程 480m → +50m×9 → 线索按 200/60 解锁 → ≤30m 自动「到了」→ 开盒 → 揭晓卡 → 收进图鉴（+XP、toast、成就 toast、写库）→ 分享（动态置顶、toast）→ 图鉴 24 格 / 圈子 6 条动态 / 成就进度 / 我的 XP 全部一致；刷新后数据仍在

## 6. 与设计文档的取舍（重要）

实现以 `docs/design-system.md` 为准；以下是文档内部或与 Swift 实现不一致处的处理：

1. **周榜老陈的分数**：Swift `SocialFeed.leaderboard` 给老陈 320 分，但 design-system §7 要求「本人第 4（305 分）」。320 > 305 会让本人掉到第 5，因此原型将老陈设为 **285**，保证「阿澈 305 · 第 4」。若改为 320，则本人变第 5。
2. **收录 toast**：§5.4 示例写作「已收录 · 惊喜值 +40」，但真实收益为 `40 + 稀有度加成`（稀有 = +50，见 `BlindWalkStore.collect`）。原型显示实际值，稀有卡即 **+50**。
3. **演示卡片日期**：`DemoData` 用 `index + 2` 天前，§5.1 首页示例文案是「已是 3 天前」，原型取 `index + 3`，让首页与设计稿逐字一致。
4. **首页「继续 · 480 m」小胶囊**：§5.1 未列出，但没有它无法从首页回到正在进行的旅程（旅程页隐藏 tab）。仅在有进行中盲盒时出现。
5. **区域名称**：设置页 chips 用「河边」（§5.2），揭晓卡/地图小字用「河岸」（§5.4 / `PlaceCatalog` 注释）。两套词都按文档保留，映射在 `data.js` 的 `AREAS[].word`。
6. **图鉴「稀有」筛选**：按统计口径「非普通」（稀有 + 史诗 + 隐藏）过滤，与「稀有 7」一致。
7. **旅程进度持久化**：§7 说「存内存即可（刷新可重置）」，原型顺手写进 localStorage（刷新不丢），属于超集，不影响演示。
8. **`?fresh=1`**：同时清空动态流，以便查看圈子空态文案「还没有人分享今晚的惊喜。」；新用户仍可在设置里开第一盒。

## 7. 已知限制

- 全部地点为**虚构演示数据**，不接真实地图瓦片 / GPS / 后端；「模拟步行 +50m」「我到了」是原型专用按钮。
- `file://` 下 `navigator.clipboard` 可能被浏览器拒绝，复制同频码失败时降级为 toast 直接显示 `K7M2QX`。
- emoji 的观感依赖系统字体（macOS / iOS 最佳）。
- 手表页为静态视觉稿，不含真实 `WatchConnectivity` 同步。
- 深色模式未实现（MVP 仅浅色，与设计一致）。
- 「隐私与安全 / 关于 / 清除演示数据」为本地交互演示，不含真实账号与合规流程。
